# 🚗 ECU Telemetry API

Realtime ECU Telemetry Dashboard built with ASP.NET Core, SignalR and SQL Server.

 Features

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- SignalR Realtime Communication
- Live Dashboard
- Swagger API Testing
- Telemetry Analysis System

 Technologies

- ASP.NET Core 8
- SignalR
- Entity Framework Core
- SQL Server
- HTML/CSS/JavaScript
- Swagger

 Live Dashboard

Realtime telemetry updates:
- RPM
- Temperature
- Speed
- Fuel Level
- Warning Status
